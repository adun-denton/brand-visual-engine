# Local initialization and resume prompt

Instruction set: visual-os-ops-v2. Run in a sufficiently authorized local agent environment.

## Copyable operator prompt

Install or resume Brand Visual Engine from https://github.com/adun-denton/brand-visual-engine.

Read the public README and INSTALL.md, then the instructions pinned to the selected approved release. Inspect this machine and any existing BVE installation before provisioning. If there is no approved release, report that fact; do not substitute an unmerged branch unless I explicitly supplied a development packet.

Resolve an explicit private project root and stable project ID. Reopen the selected compatible project without resetting it. Initialize a new project only in a suitable new destination, using the supported initialization command. Record software, instruction, runtime and staging mappings. Preserve existing assets, settings, local instruction additions and history.

Inspect available native tools, worker configurations, filesystem access and browser capture without consuming image-generation quota. Unknown capabilities remain unverified. No paid API or new credentials are prerequisites.

Install/start only within my authorization. Ask only for essential unresolved choices or additional authority. Do not stop unrelated processes. Verify the running version and project identity, give me the actual local BVE URL, and explain how to stop and resume it.

Read instructions/AGENTS.md for role routing, then the assigned role from the compatible installation. Main chat owns creative discussion; BVE owns visual records; the Butler uses supported operations. Do not create a Foreman or a persistent installer agent.

Explain which review, continuation and export features actually work in this version. Do not claim planned capabilities are implemented.

## Development candidate override

Only when the operator explicitly supplies BVE-VOS-01 or a successor approved coding/testing packet may its exact commit be used instead of a release. Record that this is a development candidate. The override authorizes only the packet's scope; it is not public distribution or a live generation allowance.

## Resume rule

Read the project configuration and canonical pending jobs/submissions first. Never reconstruct authority from a chat summary or create a replacement project to hide a conflict. Interrupted invocation does not grant another attempt. Preserve saved reviews even if no Butler session is active.
