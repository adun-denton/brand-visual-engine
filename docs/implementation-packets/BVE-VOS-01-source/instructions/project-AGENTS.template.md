# BVE private project instructions

This template is installed only into a new or explicitly selected private project root. It must not overwrite an existing AGENTS.md or local additions.

Read bve.project.json first. Resolve the stable project ID, runtime and staging roots, current installation, compatible application version and instruction version. If the manifest is absent, inconsistent or unsupported, report the issue; do not initialize over existing data.

Read the installed instructions/conductor.md, generator.md and butler.md at the version selected by this project's configuration. Read instructions.local.md if present. Preserve local additions and report compatibility conflicts.

Use public INSTALL.md and docs/project-initialization-prompt.md for setup/resume. Private planning repositories are not operational dependencies.

BVE runtime records own visual history, artifacts, jobs, review and acceptance. Conversations and capsules are navigation, not replacement authority. Use the owning application's supported operations; do not edit database files.

Keep software, authoritative runtime, staging, exports and closed backups distinct. No generated/client assets or local identifying paths belong in public GitHub reports. Never synchronize a live database on the assumption it is safely shared.

Read unfinished jobs and reviews on resume. Do not repeat generation automatically. Human submission must survive agent absence. Selection, submission, operational verification and acceptance are separate.
