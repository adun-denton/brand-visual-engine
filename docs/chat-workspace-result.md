## Actual installed protocol probe

The pinned binary reports `codex-cli 0.162.1`. Stable and experimental schemas were generated from
that binary. The integration uses stdio JSON-RPC, MCP and experimental empty `environments`; no
experimental dynamic tools. Selected experimental schema hashes are in the
[synthetic protocol receipt](evidence/chat-protocol-check.json).

A loopback synthetic Responses receiver captured the **actual binary's** effective tool catalogue
under an adverse request for execution, filesystem, browser, account and delegation access. Initial
feature flags alone still advertised execution/delegation from the default profile; that probe failed.
The restricted profile plus empty environments removed those capabilities. The final receiver saw
only MCP discovery and the six scoped BVE tools. Discovery returns no file resources. This establishes
the installed catalogue boundary together with dispatcher rejection tests; it is not a live model
adversarial conversation. The receiver deliberately returns HTTP 400, and the protocol turn fails.
That failure is the expected offline probe termination, never an inference-success receipt.

## Limits and review

Credentials remain private. Observed real model/usage/cost/plan telemetry is unknown. Prepared jobs
show unavailable production images; an injected engine proves geometry/receipt handling only. Strict
native returns currently require matching dimensions and unchanged outside pixels. Account renewal,
thread resume, image inputs and streamed real-model tool calls still require a bounded account trial
after eligibility/license and account/model/turn-limit review. Windows credential ACL support is gated.

Visual review inspected desktop 1440 and narrow 390 layouts and both fictional briefs. It identified
and repaired an opaque-iframe image failure and a composer draft leaking across project switches.
Browser assertions now check a decoded image and an empty sent composer. Candidate focus remains
pinned to exact versions; incomplete/cancelled/stale turns cannot activate drafts. Legacy browser
fixtures opt into optional controls explicitly, and their original semantic assertions remain.

Initial incomplete/failing checks are retained separately from passing receipts. A duplicate download
selector was scoped to the legacy interface, sandboxed initialization was guarded, and canvas polling
now refreshes the exact preview when selection changes. No paid calls, delegation, merge or deployment
were performed. Coordinator independent source/evidence review and actual account verification remain
required. Setup and full-root rollback are in [the operator guide](chat-workspace.md).
