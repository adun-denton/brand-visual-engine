## Limits and rollback

Manual host transfer/claims are operator attestation. A package digest is not authentication, and BVE
cannot physically stop repeated manual invocation of downloaded inputs. The native host/original-byte
bridge is unselected and untested; exact output dimensions may be incompatible. No resizing workaround
or machine-verified generation claim was added. New records conservatively block admission when
canonical evidence is missing; recovery is separate work. Received historical originals do not gain
current membership or acceptance. Selection, Library save and acceptance are separate.

There were zero actual account/model/image/GPU calls, image-provider installations, live MCP transport,
protected-root accesses/migrations, merges or deployments. Pinned repository-standard offline CLI and
fixture tooling are not live provider execution. Automatic communication, actual generation/refinement,
designer usefulness and independent acceptance remain separate. Task003/015 stay in progress.
